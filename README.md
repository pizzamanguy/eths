# Escape the Hungry Shark (pygame port)
This is based off of [this game](https://scratch.mit.edu/projects/653834126/) made in Scratch.

This is a port made by me (the creator of the scratch version)

To run the source code, install **pygame-ce** using this command in a terminal window: ``pip install pygame-ce``

Obviously to install pygame you need to install [Python](https://www.python.org/downloads/)

**Some of this code was AI-Assisted, since this is my first every python project**
