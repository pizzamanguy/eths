**Some of this code was AI-Assisted, since this is my first ever python project**

# Install guide
**This game is still in Pre-Alpha, so don't expect releases soon. This guide shows you how to run the python file (the entire game currently)**

## 1. Clone the repository
### Option 1: With git
**(This requires CLI [git](https://git-scm.com/install/). Make sure [git](https://git-scm.com/install/) is installed on your computer)**
1. Open command prompt/windows powershell/terminal with your preferred way
2. Run the command ``git clone https://github.com/pizzamanguy/eths.git location-to-store-file``

*(Replace `location-to-store-file` with the path you want to store the repo, obviously)*

### Option 2: Manually
1. Click the green code button on the repo page
2. Click download zip
3. Extract the .zip file

## 2. Install dependencies
**(If you already have python and pygame-ce installed, run `eths.py`)**
1. Install [python](https://www.python.org/downloads/)
2. Once installed, open a terminal/command prompt window and run the command: ``pip install pygame-ce``
3. After pygame-ce is installed, you can now run `eths.py` where the files were extracted
